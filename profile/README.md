# MellaMate – Global Payment API and Wallet MVP

## Overview

MellaMate is a blockchain-based global payment platform developed as a Final Year Project at Addis Ababa Science and Technology University. The system provides a payment API for merchants and a digital wallet for users, enabling secure and low-cost cross-border transactions using the Stellar network and Soroban smart contracts.

## Features

* User wallet registration and authentication
* Send and receive digital assets
* Transaction history and reporting
* Merchant payment API integration
* On-chain transaction validation
* Automated fee calculation
* Basic KYC verification
* Web and mobile wallet interfaces

## Technologies Used

* Frontend: React, Flutter
* Backend: FastAPI (Python)
* Blockchain: Stellar Network, Soroban Smart Contracts
* Database: PostgreSQL
* Authentication: JWT
